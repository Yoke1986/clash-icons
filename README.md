# Clash icons

为 Clash Verge 分组提供 PNG 图标的独立资源仓库，共 27 张图片。

## 目录

- `icons/`：服务、国家/地区和通用代理图标。
- `sources.json`：每张图片的原始来源、尺寸、大小和 SHA-256。
- `NOTICE.md`：Qure 转载出处与品牌权利说明。
